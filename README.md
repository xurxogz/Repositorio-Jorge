# Repositorio-Jorge
<h2>Nombre del proyecto</h2>
<p>Repositorio-Jorge</p>

<h2>Descripción:</h2>
<p>Este proyecto es una implementación de lógica de negocio en PHP orientada a objetos para la gestión de inventarios. Permite la creación de productos, el seguimiento de sus precios y el control de existencias mediante un sistema de ventas integrado que evita el sobregiro de stock</p>

<h2>Tecnologías usadas</h2>
<p>Lenguaje: PHP 8 y phpDocumentor (estándar PSR-5/PSR-19)</p>

<h2>Características principales</h2>
<ul>
  <li>Gestión de Entidades: Definición clara de productos con propiedades de nombre, precio y stock.</li>
  <li>Seguridad de Datos: Uso de modificadores de acceso (public, private) para proteger la integridad del inventario.</li>
  <li>Lógica de Ventas: Método validado que descuenta unidades automáticamente y emite alertas en caso de stock         insuficiente.</li>
</ul>

<h2>Requisitos</h2>
<p>Tener PHP instalado (versión 7.4 o superior recomendada por el uso de tipos) y phpDocumentor si deseas regenerar la documentación técnica</p>

<h2>Instalación</h2>
<p>Haz clic en el botón "Code" y selecciona "Download ZIP" (o clona el repositorio). Descomprime el archivo en tu servidor local (XAMPP, WAMP, Laragon) o en tu entorno de desarrollo. Asegúrate de que el archivo Producto.php esté en un directorio accesible.</p>
